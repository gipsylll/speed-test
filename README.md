# Internet Speed Test

Консольная утилита на Python для измерения скорости скачивания по HTTP(S). Выполняет **10 последовательных запросов** к указанному URL: каждый ответ полностью считывается до начала следующего запроса.

## Требования

- Python 3.13
- [uv](https://docs.astral.sh/uv/getting-started/installation/)

## Установка и запуск

```bash
uv sync
uv run python speed_test.py "https://proof.ovh.net/files/10Mb.dat"
```

Адрес передаётся аргументом командной строки. В примере используется тестовый файл OVHcloud; можно подставить любой доступный URL файла по HTTP или HTTPS.

Для справки по аргументам:

```bash
uv run python speed_test.py --help
```

> Публичные серверы могут ограничивать частые скачивания и возвращать HTTP 429. В таком случае используйте другой тестовый сервер или собственный URL. Скрипт не обходит ограничения сервера.

## Результаты

После каждого запроса выводятся количество полученных байт и затраченное время. После десяти запросов — итоговая статистика:

```text
1/10: 10,485,760 bytes in 2.070 s
 ...
10/10: 10,485,760 bytes in 1.813 s

Average request time: 2.237 s
Total downloaded:     104,857,600 bytes (100.00 MiB)
Download speed:       37.50 Mbit/s
```

*Числа приведены для примера.*

- **Среднее время запроса (с)** — сумма времени всех запросов, делённая на 10.
- **Общий объём (байты, MiB)** — сумма размеров полностью прочитанных тел ответов; 1 MiB = 1 048 576 байт.
- **Скорость (Mbit/s, Мбит/с)** — `общий объём в байтах × 8 / суммарное время в секундах / 1 000 000`.

Измеряется эффективная скорость HTTP-загрузки с конкретного сервера, а не максимальная пропускная способность интернет-канала: на результат влияют задержки, установление соединения и производительность сервера.

## Тесты

```bash
uv run python -m unittest discover -s tests -v
```

Тесты используют локальный HTTP-сервер и не требуют доступа к внешним сайтам.

## Проверка качества кода

Инструменты разработки вынесены в отдельную группу зависимостей `dev`: **Ruff** (линтинг и форматирование) и **BasedPyright** (проверка типов).

Установить группу:

```bash
uv sync --group dev
```

Запустить проверки:

```bash
uv run --group dev ruff check .
uv run --group dev ruff format --check .
uv run --group dev basedpyright .
```

Автоматически исправить поддерживаемые нарушения и отформатировать код:

```bash
uv run --group dev ruff check . --fix
uv run --group dev ruff format .
```

При сетевой или HTTP-ошибке программа завершает измерение с ненулевым кодом возврата.
